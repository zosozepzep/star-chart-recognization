
# 🚀 SRCT Pipeline 日报 - 2026.05.13

## 🌟 核心架构突破 (Core Architecture Upgrades)

- **实现 Map-Reduce 多进程 PSF 拟合引擎**
    
    - 彻底重构 `psf_fitter.py`，将计算逻辑剥离为顶层纯函数，极大压缩了 Python 进程间通信（IPC）的序列化开销。
        
    - 引入 `zip(tasks, results)` 强绑定机制，完美修复了边缘星点截断导致的异步并发索引错位 Bug。
        
    - **性能收益**：单帧几千颗星的亚像素级形态学（FWHM、椭率、残差比）拟合耗时从秒级压缩至毫秒级。
        
- **重构卡尔曼滤波器的绝对时序基准**
    
    - 在实战指挥中心（`combat_mission.py`）中，废除高风险的按文件名“字典序”排列。
        
    - 引入基于 FITS 头文件 (`MJD-OBS` / `DATE-OBS`) 的绝对物理时间提取模块。
        
    - **工程意义**：彻底杜绝了因文件命名不规范导致卡尔曼运动学推演（Predict）崩溃的时序错乱问题。
        

## 🔬 算法与逻辑深度优化 (Algorithm Enhancements)

- **SNR 纯净信噪比探测机制 (对标 SExtractor)**
    
    - 废弃粗糙的“全局底噪阈值”，在 `main_pipeline.py` 中引入局部自适应信噪比图（`snr_map = data_sub / rms_map`）。
        
    - 通过底层矩阵除法，在保持极高计算速度的同时，强制压平了图像边缘暗角和局部星云的噪声起伏，大幅降低假阳性率。
        
- **彻底消灭 $O(N^2)$ 计算泥潭**
    
    - 在大幅降低探测阈值后，原始的双重循环去重逻辑导致 `CandidateGenerator` 严重阻塞。
        
    - 重构 `_deduplicate`，引入 `scipy.spatial.cKDTree.query_pairs` 算法。将空间邻居查询的时间复杂度降维至 $O(N \log N)$，即使单帧涌现数万个候选点，系统依然能在一秒内完成选票合并。
        

## 📊 数据管线与诊断工具 (Data Pipeline & Diagnostics)

- **建立 Level 1 / Level 2 双轨数据输出系统**
    
    - **Level 2** (`final_catalog.csv`)：输出经卡尔曼关联与物理终审法庭（持久度 > 60%，符合匀速直线运动）确认的真实空间碎片/恒星轨迹。
        
    - **Level 1** (`all_raw_detections.csv`)：全量倾泻单帧提取出的所有原始星表，为底层算法对比提供详尽的数据弹药。
        
- **研发 KD-Tree 交叉匹配与可视化“验尸”引擎**
    
    - 新建 `cross_match_diagnostics.py`，通过 KD 树实现与 SExtractor 标准星表的毫秒级交叉匹配。
        
    - 解决跨平台路径解析错误与 Pandas 读取非标 CSV 的格式兼容问题。
        
    - 实现带有底色安全垫的安全对数拉伸（`LogNorm`）渲染，用绿圈和红圈在原图上直观标定“双方共识”与“孤儿异常点”，为后续调参提供了上帝视角。
