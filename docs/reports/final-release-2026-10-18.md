## 冻结、源码包与离线包

源码 ZIP 中的 `SOURCE_MANIFEST.json` 覆盖所有分发源码、配置和文档，包括新生成的
`RELEASE.json`。后者固定版本、CPU 镜像 ID、官方 15 张 FITS 的完整校验值、默认帧号
及正式算法选择。启动器先核验，再按镜像 ID 运行，不依赖可被重新指向的镜像标签。

通用 PowerShell/Bash 容器入口也已明确使用 `--pull=never --network none`。
完整离线包另带原始 FITS、CPU 镜像归档、验证报告、原始评估 JSON 和演示手册；
源代码 ZIP 不含输入数据、镜像或生成图像，继续执行 200,000,000 字节上限。

发行目录为 `dist/final-20261018/`。最终 ZIP 大小、SHA-256、解压副本断网复验、
输出比对和完整离线包校验统一记录在该目录的 **`release-receipt.json`**，避免把发行包
自身的校验值写回包内造成循环。程序和数据复验通过后才生成这份最终成功回执。

CPU 镜像：`sha256:28c1d4faab0c13048f74c9c4de963aff8a7e56844f518f164cf6132cb9894dc0`。
官方数据不含完整目标真值；候选身份、精确轨道、更暗快速源完备性、非高斯 PSF 和
跨设备泛化仍在当前能力边界之外。最终交付不声称解决这些问题。
